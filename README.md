# RADAR — Agente de Análise de Impacto e Risco de Requisitos

> Projeto avaliativo M2.2 — IA para Desenvolvedores [T1]. Em desenvolvimento.

RADAR recebe um requisito de mudança (Issue do GitHub), coleta evidência real do
código e do histórico do repositório, cruza com uma base de padrões de impacto, e
produz um parecer estruturado de risco — publicado como comentário na Issue de
origem, com aprovação humana obrigatória abaixo de um limiar de confiança.

Especificação completa: [docs/PRD-RADAR-Agente-Impacto-Risco.md](docs/PRD-RADAR-Agente-Impacto-Risco.md)

Este README será expandido com arquitetura, instruções de execução, cenários de
uso e evidências conforme o desenvolvimento avança (ver seção 5.2 do PRD).
